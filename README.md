## ⚡ The Problem We Solve
Google Play now requires all personal developer accounts to maintain **at least 20 testers for 14 continuous days** before requesting production access. 

Forums and Reddit exchanges often fail because:
- Testers uninstall after 1-2 days, resetting the developer's 14-day countdown.
- Automated bots and fake accounts get flagged by Google's algorithms.
- Unmonitored testing tracks provide zero real feedback.

## ✨ Key Features
- **100% Free Community Exchange:** Pure mutual testing. Devs helping devs with zero fees.
- **Daily Feedback Logging:** Verified check-in system with required feedback notes that you can submit directly to Google Play Console as proof.
- **Overflow Safety Buffer:** We coordinate extra testers to protect your 14-day streak against dropouts.
- **Strict Anti-Fraud Link Validation:** Verified Google Group and Play Store opt-in structures.
- **Interactive Progress Dashboard:** Real-time milestone tracker (`X / 20 Testers Joined`, `Y / 20 Completed 14 Days`).

## 🛠️ Tech Stack
- **Framework:** Next.js 16 (App Router)
- **Database & Auth:** Supabase (PostgreSQL with Row Level Security)
- **Styling:** Tailwind CSS (Dark Mode & Ultrawide Optimized)
- **Notifications:** Resend API
